01

系统优势

相比人工逐平台发布，mpau 在效率、合规与安全上做了体系化设计。

🚀一次创作，全网分发

同一素材一键投向 10+ 平台，支持视频、图文、定时发布与挂商品，告别重复搬运。

✨AI 差异化文案

一条人工标题，AI 按各平台风格与字数限制生成差异化文案，自动校验极限词，拒绝一键同文。需先在设置中配置 LLM API Key（任意 OpenAI 兼容接口，推荐 DeepSeek）。

📦批量审阅式发布

导入 → AI 生成 → 人工矩阵审阅 → 批准 → 限速发布 → 导出报告，全程可管控、可追溯。

🛡️内置风控体系

同平台同账号串行 + 跨账号并发受限、条间间隔、每账号日上限、视频指纹防重发，最大限度降低平台风控风险。

🔒数据本地私有

账号 Cookie、任务数据、LLM Key 全部保存在本机，不上传任何云端；网页后台默认仅本机访问并启用令牌认证。

🧩三种使用方式

网页后台开箱即用（安装版双击即用）；CLI 适合脚本与定时任务（需源码版）；Agent Skills 供外部 AI Agent 读取后调用 CLI——系统本身不含对话界面，需自备支持 Skill 的 Agent 工具。

02

快速开始

两种使用方式，按需选一种即可：安装版适合直接上手使用（免环境，双击 exe 即装即用）；源码版适合开发与 Agent 集成（需 Python 3.10–3.12，CLI 与 Agent Skills 只在源码版可用）。

方式一：安装版（推荐，免环境）

下载并双击安装包 mpau-setup-<版本>.exe，按向导一路下一步即可（免管理员，装到 %LOCALAPPDATA%\Programs\mpau）。

  • Python 运行时与浏览器内核已内置，无需自行安装 Python / Chrome
  • 可选「创建桌面快捷方式」「开机自动启动」；安装完成后会自动启动并打开后台界面
  • 以后每次使用：双击桌面「mpau 发布台」图标即可（自动拉起后台并打开界面）
  • 关闭窗口后系统在桌面右下角托盘继续待命；右键托盘图标可「打开主界面 / 退出 mpau」

方式二：源码版（开发 / Agent 集成 / 使用 CLI）

环境要求：Python 3.10–3.12、uv；浏览器内核随依赖安装，系统 Chrome 可选。

uv venv && .venv\Scripts\activate
uv pip install -e .
python -m patchright install chromium
mpau --help                            # 验证安装

七步发出第一条内容

启动网页后台

安装版：双击桌面「mpau 发布台」，界面会自动打开（无需记地址，也无需手动输令牌）。
源码版：项目根目录执行 uv run --extra web python web/app.py，打开启动输出里带 ?token= 的完整链接。

扫码登录账号

选平台 → 输入账号昵称 → 点「登录（扫码）」，用手机 App 扫码确认

确认登录成功

任务状态变为 success，账号进入「已登录账号」列表并自动显示平台真实昵称，长期免登

配置 AI 文案引擎（用 AI 生成文案前必做）

顶栏 ⚙️ 设置 → 填「接口地址 base_url」「API Key」「模型名」（推荐 DeepSeek：https://api.deepseek.com/v1 + deepseek-chat，Key 到 platform.deepseek.com 申请）→ 点「测试连接」确认可用 → 保存。
不配也能用：登录、发布、审阅、报告全部正常；只有「一键生成全部文案 / 重新生成」会失败并提示未配置 Key。

导入素材，建立批次

「选择文件夹」扫描整批视频（或「导入 CSV」按清单建批次，也可「选择单条视频」发一条）

试跑演练（模拟上线）

勾选「试跑」+ 有头模式提交一次：浏览器自动填好全部字段但不点发布，现场核对

正式发布

去掉试跑再次提交，「任务队列」实时跟踪进度与日志，失败可定位原因重试

上线建议：支持试跑的平台（抖音 / 拼多多 / 天猫 / 京东）首次使用都先做一次「试跑演练」，确认标题、封面、商品挂载无误后再切换正式发布。快手、小红书、视频号、百家号当前不支持试跑，勾选「试跑」对它们无效（仍会真实发布），这类平台请用「有头模式 + 单条视频」小批量验证。
03

网页后台

账号管理 + AI 文案引擎 + 任务队列 + 批量编排，全部数据保存在本机数据目录的 data/mpau.db，重启自动恢复。

启动与访问

安装版（推荐）：双击桌面「mpau 发布台」图标即可——系统自动拉起后台服务，并用内置 Chromium 浏览器以独立窗口打开界面（与你电脑的默认浏览器无关，无需手动输入令牌）。关闭窗口后服务在托盘常驻，右键托盘图标 →「打开主界面」可随时再次打开。

源码版（开发者）：

# 本机使用（默认 http://127.0.0.1:8898）
uv run --extra web python web/app.py

# 局域网共享（团队内访问，一键配好防火墙；同样需要令牌）
powershell -ExecutionPolicy Bypass -File web\start-lan.ps1

后台启用令牌认证：启动时终端会打印带 ?token= 的完整入口链接，打开一次即记住登录状态；也可在登录页手动输入令牌（令牌文件：数据目录下的 data/web_token.txt，可用环境变量 MPAU_WEB_TOKEN 固定）。

安全提示：令牌等同全部账号的操作权，请勿外发；即使开启局域网模式也严禁暴露到公网。

🔑账号管理

选平台 → 输昵称 → 扫码登录。有头模式本机弹出浏览器；无头模式（服务器）页面直接显示二维码。Cookie 本地持久保存，掉线重新扫码即可。

📦批量发布（统一入口）

单条与批量发布统一走批量流程：扫描文件夹 / 导入 CSV / 选单条视频 → 填标题 → AI 生成 → 审阅矩阵 → 批准 → 限速发布 → 导出报告。详见「批量发布流程」。

✨AI 多样发布

只写一条人工标题，AI 自动为多个平台、多个账号生成差异化文案，支持候选切换、单条重生成、合规校验，确认后一键入队。

📋任务队列

所有登录 / 发布任务实时显示状态与日志，可取消运行中任务；抖音触发短信验证时，展开任务日志即可填写验证码继续。

⚙️设置

顶栏 ⚙️ 配置 LLM（任意 OpenAI 兼容接口，推荐 DeepSeek）与风控参数（条间间隔、每账号每日上限）。Key 仅保存在本机。

💾数据与备份

任务、批次与配置持久化在数据目录下的 data/mpau.db 与 data/config.json，登录凭据在 cookies/。
数据目录位置：安装版为 %LOCALAPPDATA%\mpau-data（资源管理器地址栏粘贴即可打开）；源码版为项目根目录。备份与迁移只需整体复制这个目录。

重装 / 升级不会丢数据：数据目录独立于程序安装目录，覆盖安装或安装新版本都会继续沿用同一份账号、批次与配置。

批量发布流程

几十上百条视频一次投向多个平台的标准流程：人审文案，机器跑腿，全程留痕可追溯。

① 导入扫文件夹 / CSV
→
② 填标题每条人工标题
→
③ AI 生成分平台文案
→
④ 审阅批准矩阵逐条过
→
⑤ 限速发布账号串行 + 间隔
→
⑥ 报告导出 CSV

各环节说明

环节做什么要点
① 导入扫描视频文件夹，或导入 CSV 清单建批次CSV 每行一个视频，列：文件名,人工标题,描述,标签,定时时间,封面,商品链接,商品短标题,商品ID（快手挂车请在条目里填「商品名称」，填商品ID对快手无效）
② 填标题为每条视频填写人工标题人工标题是 AI 生成的基础，决定文案质量
③ AI 生成按「视频 × 平台 × 账号」展开条目并生成文案各平台文案自动适配字数与风格，可单条重生成
④ 审阅批准审阅矩阵中逐条核对、修改、批准只有「已批准」的条目才会进入发布队列
⑤ 限速发布系统按风控参数自动发布：同一「平台+账号」串行，不同平台/账号可并行（默认最多 4 条）可随时停止批次；中断后重新批准即可续传
⑥ 报告导出批次报告 CSV成功 / 失败 / 原因逐条留档，便于复盘

账号与商品的颗粒度

  • 多账号一键分配：平台卡片支持逐个勾选，也可点「全选 / 取消」一键切换；同一视频会按勾选的账号逐个生成发布条目。
  • 商品 ID 逐条一对一：商品 ID / 商品名称在「条目编辑」里逐条设置，只作用于本条（视频 × 平台 × 账号），复制或确定后不影响同视频的其它条目。
  • 挂车口径分平台：视频号按商品 ID（橱窗搜索挂载）；快手按商品名称（小店搜索挂载，填商品 ID 无效）；拼多多 / 天猫 / 京东按平台要求填商品链接或商品 ID（详见「平台能力对照」）。

内置风控（默认开启，保障账号安全）

机制默认值说明
账号串行 + 并发上限并发 4同一「平台+账号」同时只发一条；不同平台/账号可并行，避免单账号并发触发风控
条间间隔5 分钟可在设置中调整
每账号日上限25 条超出自动排队，防止单日过量
防重发sha256 指纹同一视频 + 平台 + 账号不会重复发布
05

命令行 CLI

统一结构：mpau <平台> <动作> [参数]，适合脚本化与定时任务。网页后台的全部能力 CLI 均可完成。

平台与动作

平台：douyin tencent pdd tmall jd kuaishou xiaohongshu bilibili baijiahao tiktok

动作：login（扫码登录）check（检查登录态）upload-video upload-note（图文）verify（短信验证）

常用示例

# 登录（有头模式弹浏览器扫码）
mpau douyin login --account shop1 --headed

# 发布视频（定时 + 挂商品 ID）
mpau tmall upload-video --account shop1 --file ./demo.mp4 \
  --title "新品上架" --schedule "2026-06-05 20:00" --headed
mpau jd upload-video --account shop1 --file ./demo.mp4 \
  --title "真实测评" --goods-id "10204078771126" --headed

# 发布图文笔记（小红书 / 抖音 / 快手）
mpau xiaohongshu upload-note --account shop1 \
  --images ./p1.jpg ./p2.jpg --title "开箱笔记" --headed

批量发布（与网页后台共用同一引擎）

mpau batch scan --dir D:\videos\0618          # 扫描文件夹建批次
mpau batch plan --batch-id <id> --platforms douyin,kuaishou
mpau batch generate --batch-id <id>          # AI 生成各平台文案
mpau batch approve --batch-id <id>           # 批准入队
mpau batch run --batch-id <id> --interval-min 5  # 限速发布
mpau batch report --batch-id <id>            # 导出报告 CSV

其余子命令：import（CSV 导入）fill（补标题）retry（重试失败）status（进度）stop（停止）list（批次列表）。

通用参数

参数作用
--headed / --headless显示浏览器界面 / 后台静默运行
--dry-run试跑：自动填好所有字段但不点发布
--schedule "YYYY-MM-DD HH:mm"定时发布
--thumbnail自定义封面图
--product-link / --product-title挂商品链接（抖音）
--goods-id挂商品 ID（视频号 / 拼多多 / 天猫 / 京东）
--goods-name挂商品名称（快手：按名称搜索关联，名称需与快手小店一致）
--debug输出调试日志（日志在数据目录下的 logs/，安装版为 %LOCALAPPDATA%\mpau-data\logs\）

07

常见问题 Q/A

打开后台时要求输入访问令牌，令牌在哪里？
安装版正常不会看到令牌页：系统用内置 Chromium 浏览器以独立窗口打开后台，与你的默认浏览器无关，令牌自动带上。只有内置内核缺失、回退到系统浏览器时才可能需要手动输入：打开本机的 data/web_token.txt 复制令牌粘贴到登录页（开发模式见终端打印的带 ?token= 完整链接）。想固定令牌可设置环境变量 MPAU_WEB_TOKEN。
关掉窗口后系统还在运行吗？怎么完全退出？
关掉管理界面窗口后，系统仍在后台待命（桌面右下角托盘有「mpau 发布台」图标）。要完全退出：右键托盘图标 →「退出 mpau」；双击托盘图标或选「打开主界面」可重新打开窗口。注意：退出会中断正在执行的发布任务，退出前请确认任务队列已空闲。
登录成功后账号显示的是什么名字？
登录时填的是本地别名（如 douyin1，用于 Cookie 文件命名）；扫码确认后系统会在后台自动抓取平台真实昵称并回填显示（有几秒延迟，属正常）。没抓到也不影响使用，别名永远是主键。
登录态能保持多久？掉线了怎么办？
Cookie 保存在本机 cookies/ 目录，一般可维持数天到数周（视平台而定）。掉线后用 mpau <平台> check --account 昵称 检查，失效则重新扫码登录即可，历史任务与数据不受影响。
抖音发布时要求短信验证怎么办？
网页后台：展开对应任务的日志，会出现验证码输入框，提交后继续发布。CLI：另开终端执行 mpau douyin verify --account 昵称 --code 123456。
重启服务后，之前的任务和批次还在吗？
在。所有任务与批量数据持久化在数据目录下的 data/mpau.db（安装版 %LOCALAPPDATA%\mpau-data\data\mpau.db）。重启时运行中的任务会标记为「已中断」，失败的条目可重试，批次可重新批准后续传。
会不会被平台限制？如何降低风险？
系统已内置账号级串行、条间间隔（默认 5 分钟）、每账号日上限（默认 25 条）与防重发机制。建议：新账号先「试跑（支持的平台）+ 有头」观察；不要突然提高发布量；多账号分摊发布。
同一个视频会不会重复发到同一平台？
不会。系统按「视频 sha256 + 平台 + 账号」做指纹防重发，重复提交会被自动跳过（批量运行可用 --force 强制）。
AI 文案需要先配置吗？不配会怎样？
需要先配好 LLM API Key，AI 生成文案才能用。位置：顶栏 ⚙️ 设置 → 填写「接口地址 base_url」「API Key」「模型名」，推荐 DeepSeek（https://api.deepseek.com/v1 + deepseek-chat，Key 到 platform.deepseek.com 申请），填完点「测试连接」确认可用再保存。
不配也不影响登录、扫码、发布、审阅、导出报告——只有「✨ 一键生成全部文案」和「⟲ 重新生成」会失败并提示未配置 Key；此时可在表格里手动填写标题、描述、标签后照常发布。Key 仅保存在本机（见"数据与备份"一节的数据目录），不会上传或外传。
AI 文案用什么模型？Key 存在哪里？
支持任意 OpenAI 兼容接口，推荐 DeepSeek。在网页后台「设置」中填写，Key 仅保存在本机数据目录下的 data/config.json（安装版完整路径 %LOCALAPPDATA%\mpau-data\data\config.json），不会上传或外传。
能不能直接和系统对话操作（智能体对话）？
不能。系统本身不含对话界面，也没有内置的智能体聊天功能。如需 AI 驱动：把源码仓库里的 skills/ 目录交给支持 Skills 的外部 Agent 工具（如 Kimi Code、Claude Code 等），由它读取技能说明并调用 CLI 完成登录、检查、发布，接入方式见源码仓库的 docs/agent-integration.md（此能力属源码版）。
多人同时使用冲突吗？
发布引擎保证同一「平台+账号」串行执行；不同平台/账号之间受并发上限约束（默认 4）。多人通过同一局域网后台提交的任务会一起排队调度，不会对同一账号并发冲突；但同一批次的审阅操作建议由一人负责，避免重复批准。注意：局域网内每个人都需持有访问令牌。
出错了去哪里看日志？
网页后台「任务队列」展开任务即可看实时日志；CLI 与后台日志文件在 logs/ 目录，按平台分文件（如 logs/douyin.log）。
