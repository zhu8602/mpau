# mpau 商业化方案 v1.0

> 适用产品：mpau（CLI + Web 管理后台，本地部署，`127.0.0.1:8898`）
> 定位：面向电商商家 / 矩阵工作室的「可定制、带商品挂载的多平台批量发布 + AI 文案」工具
> 制定依据：市场已有同类批量发布平台（功能同质化），本产品真实差异化 = 电商内容挂载 + 多店铺多账号矩阵 + AI 文案分发 + 可定制（业务已验证、适配度高）。因此定价策略：**标品部分地板价去卷，非标部分（定制 / 部署 / 服务）卖出溢价。**

## 1. 定位与差异化

### 1.1 一句话定位

> 别人帮你「发内容」，mpau 帮你「发电商内容」：视频、图文到 10 个平台，商品挂载、多店铺账号、AI 文案一次搞定，还能按你的业务流程改。

### 1.2 三个真实差异化（其他工具抄不动的部分）

1. **电商内容分发**：抖音（商品链接）、视频号（微信小店/橱窗）、PDD/多多视频、天猫/淘宝光合、京东（商品 ID）——市场上同类工具多数只做内容平台，做不了电商挂载/平台审核适配。
2. **多店铺多账号矩阵**：每平台多账号并存、账号映射（可多选）、同平台多账号自动差异化标题——这是业务验证过的真实需求，也是按账号数计价的基础。
3. **可编程 + 可定制**：CLI + Agent Skill，可接入脚本/AI Agent/客户系统；定制交付快（需求评估 1~3 天、交付 3~7 天）。客户不用迁就工具，工具按客户改。

### 1.3 竞品对照（对外话术基准）

| 维度 | 市面通用工具（蚁小二/融媒宝/易媒等） | mpau |
|---|---|---|
| 平台范围 | 内容平台 5~8 个 | 内容 + **电商 10 平台**（含 PDD/天猫/京东/微信小店） |
| 商品挂载 | 多数不支持 | 商品链接/商品 ID 原生支持 |
| 多店铺账号 | 单账号为主，切号手动 | 矩阵账号映射 + 差异化标题 |
| AI 文案 | 通用模板 | 批次共用提示词 + 平台调性 + 单条人工标题 |
| 定制能力 | 无 / 很贵 | 按业务流程改，3000 起，3~7 天交付 |
| 部署 | 云端 SaaS | **本地/局域网部署**，数据不出门 |
| 价格 | 60~300/月 | 19.9/月 起 |

### 1.4 目标客户分层

| 客户 | 特征 | 付费点 | 对应档位 |
|---|---|---|---|
| 个体卖家 | 1~3 个账号，一天发几条 | 便宜、多平台、AI 文案 | 个人版 |
| 矩阵工作室 | 5~20 个账号，批量+定时 | 多账号映射、批量队列、报告 | 工作室版 |
| 电商运营公司 | 20+ 账号、多人协作 | 团队、API、部署 | 矩阵版/私有部署 |
| 代理商/服务商 | 卖工具给上面的人 | 进货差价 | 卡密/代理价 |

## 2. 定价体系

### 2.1 定价原则

- 入口价格对标竞品 **1/3 ~ 1/2**（卷得有理：功能同质化，但你的适配和服务更好）。
- **按账号数计价**，不按平台/次数计价：账号涨，档位自然升，迁移成本让客户离不开。
- AI 文案：订阅含额度（甜点），超额走积分（成本 1~2 分/条，卖 5 分/条级，利润百倍）。
- 定制/私有部署**不放价**：这是差异化的钱，也是售后的钱。

### 2.2 价格表（建议价，可按数据微调）

| 档位 | 价格 | 年付 | 定位 |
|---|---|---|---|

### 2.3 促销与裂变

- 首月尝鲜：个人版 **¥9.9/首月**、工作室版 **¥39/首月**（首月是转化关键，价格锚点建立后按原价续费）。
- 邀请裂变：邀请 1 人成功付费 → 送 15 天同档位顺延（或送 1000 积分，二选一，首期用手动发放验证 ROI）。
- 年付折扣本身（约 5~6 折）已经是最大促销，避免频繁打折伤价格体感。
- 代理价（见 5.3）：进货 5 折，100 个起 4 折；代理可再分销给工作室。

### 2.4 授权体系（授权码怎么用）

- 形态：**机器码绑定 + 在线激活**（联网校验，策略见 7.3）。
- 激活码字段：`license_key`（前缀+随机，服务端只存 hash）、`tier`、`expire`、`credits`、`machine_id`（绑定后锁定）。
- 换绑：每授权每年免费 2 次，之后 ¥19.9/次（防二手倒卖）。
- 永久版话术：「**¥399 买断，含 1 年更新；之后 ¥99/年 续维护**」——把「买断+维护费」立成市场习惯，否则会被售后拖死。
- 注意事项：永久版功能 = 工作室版，不含矩阵版/团队/API（那些维持订阅，保护现金流）。

## 7. 技术落地：授权 / 积分 / 账号系统

### 7.1 现状与目标

现在：单机 Flask + SQLite + 访问令牌（`data/web_token.txt`）。
目标：**本地重活留在本地 + 云端轻服务只做授权**（注册/登录、卡密、积分、激活、额度查询）。

### 7.2 云端轻服务（License Server）

- 复用同一套技术栈（Flask + SQLite 就够，或加个 Postgres），部署到 1 台轻量云主机（¥60~100/年那档），Nginx + HTTPS。
- 数据表最小集：`users`、`licenses`、`credits_ledger`（积分流水）、`keys`（卡密，只存 hash）、`devices`（机器绑定）。
- 本机 Web 后台加「登录/激活」入口，与现有 token 认证并存（token 保留为局域网/离线模式）。

### 7.3 激活与校验流程（防破解底线）

1. 启动 → 取机器指纹（CPU/主板/磁盘序列号 SHA-256）→ 查本地缓存。
2. 未激活 → 展示「激活码」输入 → 服务端下发 `tier/expire/credits/sign`（签名令牌，本地验签）。
3. 在线校验：启动时 + 每 24h 一次；**断网宽限 3 天**，超期降级只读（不能新发布）——宽限期兼顾客服窗口和售后体验。
4. 积分：本地缓存 + 服务端记账，扣减幂等；条数/额度统计以本地任务日志为准、服务端兜底对账。
5. 防破解要点：签名验签做在 Python 侧 + 关键逻辑就必然可被改（本地工具防君子不防小偷）——所以**定价逻辑简单、破解成本高于购买**才是正路（¥19.9/月 没人费力破解；¥399 永久版反而是破解重灾区，优先做联网校验）。

### 7.4 免费版限制开关

- 所有限制项（第 3 节矩阵）做成 DB/配置表，`tier` 生效时读取，改价不发版。
- 免费版强制水印/横幅（「升级解锁多账号」）但不弹广告。
